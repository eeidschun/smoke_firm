# Meeting notes naming

Use `marc_mtg_YYYY-MM-DD.md` for Marc meeting notes, where the date is the meeting date. Name the corresponding PDF `marc_mtg_YYYY-MM-DD.pdf`. Supporting documents use `marc_mtg_YYYY-MM-DD_<description>.md` (and matching PDF when present).

Store supporting CSVs in `tables/YYYY-MM-DD_<description>.csv`. Use a date recorded in the document; if it has no date, use the associated analysis date and document its origin. Update document links and generating scripts when renaming or moving files. Keep this AGENTS.md filename unchanged.

When the next meeting date is unknown, use `marc_mtg_TBD.md` (and `marc_mtg_TBD.pdf` if needed). Rename it with the meeting date once scheduled. Populate exercises section by section as directed by the user.

Meeting notes are shared directly with Marc during Zoom. Write summaries as direct prose or bullet points, without quotation marks or blockquotes framing them as suggested speaking scripts.
